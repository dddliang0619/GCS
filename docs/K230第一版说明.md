# K230 视觉第一版

## 1. 第一阶段目标

先完成最小闭环，不上 YOLO：

1. 摄像头稳定输出 320×240 RGB565 图像。
2. 分别识别红、绿、蓝色块。
3. 输出目标中心、面积和相对画面中心的偏差。
4. 连续多帧稳定后才报告有效目标。
5. 最后接入 UART，让 STM32 根据偏差控制麦轮横移。

巡线仍由 STM32 和八路巡线模块完成。K230 只在 STM32 下达视觉任务后识别。

## 2. 软件分层

```text
main.py
├─ camera.py      相机初始化与取图
├─ vision.py      颜色识别、目标筛选、稳定滤波
├─ protocol.py    STM32/K230 文本协议
└─ config.py      分辨率、ROI、阈值和筛选参数
```

第一版先运行 `main.py` 并观察 IDE 画面和串口打印。确认识别稳定后，再加入物理 UART。

## 3. K230 与 STM32 的职责

STM32 发送命令：

```text
$CMD,SEARCH,RED*\n
$CMD,SEARCH,GREEN*\n
$CMD,SEARCH,BLUE*\n
$CMD,STOP*\n
```

K230 返回结果：

```text
$VIS,1,RED,-18,24,3650,92*\n
```

字段含义：

```text
VIS,是否有效,颜色,dx,dy,像素数,稳定度
```

- `dx = 目标中心x - 画面基准x`，负数表示目标在左边。
- `dy = 目标中心y - 画面基准y`。
- 未发现稳定目标时返回 `$VIS,0,NONE,0,0,0,0*`。

STM32 是主控。K230 不直接驱动电机，只返回观测结果。

## 4. 调试顺序

### A. 相机

- 能在 CanMV VS Code 扩展中预览图像。
- 确认画面方向，必要时调整 `set_hmirror`、`set_vflip`。
- 固定相机位置后再标定颜色。

### B. 单色识别

- 一次只放一个物料。
- 使用阈值编辑器采集赛场光照下的 LAB 阈值。
- 将阈值写入 `config.py`。
- 调整最小像素数、最小区域面积和 ROI。

### C. 稳定判断

- 连续 5 帧中至少 4 帧发现同色目标。
- 中心坐标变化过大时清零稳定计数。
- 只选取符合要求的最大色块。

### D. 串口

- K230 与 STM32 必须共地。
- 只能使用开发板支持的 1.8 V/3.3 V 电平，禁止接 5 V UART。
- 双方先统一为 115200、8N1。
- STM32 当前使用 USART2；K230 UART 编号和引脚需根据实际开发板原理图配置。

### E. 底盘闭环

先只做横向对准：

```text
dx < -10：低速左移
dx >  10：低速右移
|dx| ≤ 10 且连续稳定：停车
```

横向稳定后，再加入前后距离控制。不要一开始同时调两个方向。

## 5. 验收条件

- 红、绿、蓝分别在目标距离下稳定识别。
- 空场景不会误报。
- 手、夹爪、车架不会被当成目标。
- `dx` 左右方向与底盘移动方向一致。
- 遮挡一帧不会立刻丢失，持续丢失才报告无目标。
- 视觉超时后 STM32 停车，不继续盲抓。

## 6. 版本注意事项

CanMV K230 在 V0.7 前后相机 API 有明显变化。本目录按新版 `media.sensor`、`media.display`、`media.media` 结构组织。正式上板前应记录：

- 开发板准确型号；
- CanMV 固件版本；
- 摄像头型号；
- UART 可用编号、TX/RX 引脚与 IO 电压。
